Корисні сполучення

  • handle mat купувати продукти
  • handle om бути про
  • det handler om ідеться про

Що важливо знати

Handle має три головні значення: робити покупки (handle mat), діяти (handle raskt) і handle om — «бути про щось»: Hva handler filmen om? — Про що фільм? Det handler om tillit — ідеться про довіру. Минулий — handlet.

У словнику Bokmålsordboka

  1. kjøpe, gjøre innkjøp; gå til innkjøp av gå ut og handle litt · handle inn til jul
  2. drive handel handle med dagligvarer · handle en gros
  3. være virksom, gjøre noe; gripe aktivt inn; opptre, oppføre seg ikke bare snakke, men handle · handle raskt

Сталі вирази

  • handle om – ha som innhold eller emne; dreie seg om
