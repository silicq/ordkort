Примеры

  • Jeg skal handle mat etter jobb.После работы я пойду за продуктами.
  • Boka handler om en familie i Lofoten.Книга о семье с Лофотенских островов.
  • Vi må handle raskt.Нужно действовать быстро.

Полезные сочетания

  • handle mat покупать продукты
  • handle om быть о
  • det handler om речь идёт о

Что важно знать

У handle три главных значения: делать покупки (handle mat), действовать (handle raskt) и handle om — «быть о чём-то»: Hva handler filmen om? — О чём фильм? Det handler om tillit — дело в доверии. Прошедшее — handlet.
