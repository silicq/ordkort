# Ordkort — карточки, словарь и грамматика для любого языка

Бесплатный сайт для изучения языков: карточки по темам с интервальным повторением,
словарь в духе ordbokene.no и Lexin, учебник грамматики и переводчик с разбором
каждого слова. Без регистрации, рекламы и аналитики.

## Как устроено

```
public/            сайт: HTML, CSS, JS, шрифты — раздаётся Cloudflare как статика
  _headers         заголовки безопасности (CSP и др.)
src/               Cloudflare Worker — выполняется только для /api/*
  worker.js        маршруты, проверка источника запроса
  api.js           ИИ-запросы: общий кэш → банк слов → лимиты → Groq
  prompts.js       все промпты и проверка ответов ИИ
  facts.js         проверенная справка по грамматике букмола (опора для ИИ)
  groq.js          клиент Groq с переключением моделей
  limits.js        лимиты: всплески, в час, в сутки, общий бюджет
  sync.js          синхронизация и одноразовые коды (сервер видит только шифротекст)
  db.js            D1: схема создаётся сама при первом запросе
wrangler.jsonc     конфигурация Cloudflare
```

**Данные пользователя** хранятся в localStorage браузера. На сервер уходят только ИИ-запросы
(слово, тема, текст + пара языков) — ответы копятся в общей базе и отдаются следующим людям
без траты лимита.

**Ключ Groq** живёт только в секрете Worker'а. Браузер присылает параметры, а не промпт,
поэтому API нельзя использовать как чужой бесплатный чат-бот.

**Лимиты** (меняются в `wrangler.jsonc` → `vars` или в панели Cloudflare):
`AI_PER_HOUR` = 40, `AI_PER_DAY` = 120 на человека, `AI_DAILY_BUDGET` = 2500 на весь сайт.
Человек определяется хэшем IP с солью, меняющейся каждый день; сам IP не сохраняется.

**Синхронизация без аккаунтов.** Секрет из 32 случайных байтов есть только на устройствах
пользователя. Из него выводятся id копии, токен записи и ключ AES-256-GCM. Сервер хранит
шифротекст и хэш токена. Привязка — через одноразовый код (16 символов, живёт 3 минуты,
сгорает при первом чтении) или QR-ссылку, где ключевая часть идёт после `#` и серверу
не отправляется. Есть и разовый перенос без облака.

Подробно для пользователей — на странице сайта «Как это работает» (`#/about`).

## Локальный запуск

```bash
npm install
```

Скопируйте `.dev.vars.example` в `.dev.vars` и впишите ключ Groq, затем:

```bash
npm run dev
```

Сайт откроется на http://localhost:8787 вместе с локальной базой D1.

## Деплой на Cloudflare с автообновлением из GitHub

1. Загрузите репозиторий на GitHub.
2. Панель Cloudflare → **Workers & Pages** → **Create** → **Import a repository** → выберите
   репозиторий. Команду сборки оставьте пустой, команда деплоя — `npx wrangler deploy`.
3. После первого деплоя: Worker → **Settings** → **Variables and Secrets** → добавьте секрет
   `GROQ_API_KEY` (и по желанию `IP_SALT` — любая длинная случайная строка).
4. База D1 `ordkort` создаётся автоматически при первом деплое, таблицы — при первом запросе.

Дальше каждый push в основную ветку сам выкатывается на сайт.

Без GitHub то же самое делается из терминала:

```bash
npx wrangler login
```

```bash
npx wrangler secret put GROQ_API_KEY
```

```bash
npm run deploy
```

После публикации впишите адрес репозитория в `public/js/config.js` → `repoUrl`,
чтобы на странице «Как это работает» появилась ссылка на исходный код.

## Безопасность

- Весь ввод проверяется на сервере (языки из белого списка, ограничения длины),
  ответы ИИ проходят проверку формы перед записью в общую базу.
- Запросы с чужих сайтов отклоняются (проверка `Origin`), API принимает только JSON.
- Лимиты: всплески режутся в памяти, генерации — счётчиками в D1, плюс общий суточный бюджет.
- CSP запрещает сторонние скрипты и встраивание сайта во фреймы; шрифты свои, сторонний
  запрос только один — открытый API ordbokene.no для норвежского.
- Логи запросов Worker'а выключены; счётчики лимитов, коды привязки и заброшенные
  копии синхронизации удаляются ежедневной задачей по расписанию.
- От распределённых атак защищает сама сеть Cloudflare. Если подключить собственный
  домен, можно дополнительно включить правило WAF Rate Limiting для `/api/*` и Bot Fight Mode.
